# Developer Feedback

When the user brings developer feedback, code-review findings, retest results,
architecture notes or handoff recommendations for Larena, load and apply
[../knowledge-packs/developer-feedback-intake-protocol.md](../knowledge-packs/developer-feedback-intake-protocol.md).

- Feedback is review input, not a canonical change.
- Classify each finding, decide the outcome and record its impact.
- Add recurrence prevention for accepted findings.
- Run the project-local feedback validator when present.
