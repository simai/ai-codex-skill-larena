# Goal Execution

For user-level Larena goals and stages, load
[../knowledge-packs/larena-goal-execution-profile.md](../knowledge-packs/larena-goal-execution-profile.md).

- Hierarchy: `goal -> milestone -> batch -> checkpoint/evidence -> Kaizen`.
- In Russian user-facing replies say `этап` for canonical `milestone`; accept
  `веха` only as a legacy input alias. Do not rename machine-readable process
  keys, launch records or evidence fields.
- When the user says `делай цель`, `делай в режиме цели` or `доведи до
  результата`, continue safe Larena batches until the agreed `Done When`, a
  real blocker, a runtime/destructive approval boundary or a planned human
  checkpoint.
